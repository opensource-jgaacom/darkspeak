**Active goal:** Two actual DarkSpeak instances can configure a share, authorize a contact, browse its UNIX-like virtual filesystem and download selected files interactively, with one application-wide transfer queue and UI. Prioritize a working end-to-end vertical slice over exhaustive tests. This is the **Stage 1 worklist only**; specifications define behavior, not additional automatically approved tasks.

Follow `agents.md`: implement one checked item/increment at a time; check off immediately with short evidence (test/commit); keep test registration and docs current; do not expand scope without owner approval. **Before full application builds or the two-instance test gate, coordinate with the owner as required by build rules.** Maintain security/correctness invariants throughout. No separate FTP filesystem, transfer engine, queue per feature, or protocol compatibility fallback.

### Hold the private network open

Run this in the same terminal. It creates the existing loopback-only Chutney topology, waits for readiness and prints two GUI launch commands. Fresh A/B profiles are preconfigured before launch so neither instance starts a separate public Tor daemon. Both Debug and Release settings names are seeded because the application name depends on build type.

```bash
"$DS_MANUAL_RUN/venv/bin/python" - "$DS_MANUAL_BUILD" "$DS_MANUAL_RUN" <<'PY'
import asyncio
import os
from pathlib import Path
import shlex
import sys

sys.path.insert(0, str(Path.cwd() / "tests/mcp"))
from harness import Runtime

def wait_for_operator():
    # stdin contains this script's heredoc; read the operator's terminal.
    with open("/dev/tty") as terminal:
        terminal.readline()

async def main():
    os.umask(0o077)
    build, run = map(Path, sys.argv[1:])
    runtime = Runtime(build / "bin/darkspeak", build / "_deps/chutney-src")
    try:
        await runtime.configure_tor()
        await runtime.start_tor()
        clients = [node for node in runtime.nodes if node["client"]]
        if len(clients) != 2:
            raise RuntimeError("Expected exactly two private clients")
        for label, node in zip(("A", "B"), clients):
            profile = run / label
            config = profile / "config/DarkSpeak"
            config.mkdir(parents=True, mode=0o700)
            service_port = runtime.port()
            settings = (
                "[General]\ntorMode=0\ntorCtlHost=127.0.0.1\n"
                f"torCtlPort={node['control']}\ntorCtlAuthMode=0\n"
                f"torSocksHost=127.0.0.1\ntorSocksPort={node['socks']}\n"
                f"torAppHost=127.0.0.1\ntorServiceFromPort={service_port}\n"
                f"torServiceToPort={service_port}\n"
                "autoAcceptIncomingFiles=false\n"
            )
            for name in ("DarkSpeak-debug.ini", "DarkSpeak.ini"):
                (config / name).write_text(settings)
            print(f"{label}: control={node['control']}, SOCKS={node['socks']}, service={service_port}", flush=True)
            print(shlex.join([str(build / "bin/darkspeak"), "--profile", str(profile),
                              "--log-file", str(run / f"{label}.log"), "--log-level", "debug"]), flush=True)
        print("Keep this terminal open. Close both GUIs before pressing Enter to stop Tor.", flush=True)
        await asyncio.to_thread(wait_for_operator)
    finally:
        await runtime.close()

asyncio.run(main())
PY
```

Copy each printed launch command into its own desktop terminal. Do not use `QT_QPA_PLATFORM=offscreen`. Use fresh test identities/vault prompts. In each window verify Settings → Tor: **System Tor**, loopback control/SOCKS endpoints matching its printed row, **SafeCookie**, and the printed service port as both ends of the service-port range. Here System Tor attaches to the already running private network; the GUI's Private Tor option would start another managed daemon. If these settings do not match, stop before taking the identities online.
